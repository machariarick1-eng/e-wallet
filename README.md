# e-wise

A private, local-first money management app for tracking everyday income and spending, savings goals, investments, and future purchases.

## Run it

Open `index.html` in a modern browser. No build step, account, or server is required. To use it via GitHub Pages, push this folder to a repository and enable Pages for the branch and folder containing `index.html`.

## What’s inside

- Overview with clickable balance, income, spending, and savings figures
- Dedicated Cash flow and Spending pages, plus separate transaction, savings, investment, monthly-item, and purchase-planning pages
- Income and expense tracking with categories, dates, filters, and CSV export
- Savings goals with progress tracking and contributions
- Investment holdings with invested and current values
- Purchase planning with weekly and monthly saving targets
- Monthly transaction templates, one-per-month recording, and due reminders
- Currency preference, stored data controls, and responsive layouts
- Ksh formatting by default, with a persistent dark theme option
- Individual, bookmarkable app sections and quick links from the overview figures
- Erick profile sign-in with a profile menu for Settings and Log out

## Your data

Entries are stored in this browser’s local storage on this device; they are not sent to a server. The first visit includes sample data so you can explore the app. Choose **Start fresh** in Settings to begin with an empty wallet. Export transactions periodically if you want a separate backup.

Monthly reminders run while e-wise is open. Optional browser notifications require permission and a secure site such as GitHub Pages; they do not run while the site is closed.
